# @english-sathi/admin

Admin dashboard for English Sathi operations, curriculum management, and platform telemetry.

## Features
- User & subscription management
- Lesson and curriculum authoring
- AI prompt & performance telemetry
- Analytics & reporting

## Scripts
- `npm run dev` - Start dev server at `http://localhost:3001`
- `npm run build` - Build production bundle
- `npm run start` - Run production server
